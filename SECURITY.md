# Security

Do not include API keys, recordings, transcripts or private account information
in public issues. Redact sensitive information from logs and screenshots.

For a suspected vulnerability, use GitHub's private vulnerability reporting
when available. If it is unavailable, open an issue asking for a private
contact channel without including exploit details or personal data.

Audio and optional context are sent to the service configured by the user.
Review the privacy section in README before enabling context features.
